Welcome to the **Nebula RL Platform**, an interactive educational journey designed to teach the core principles of Reinforcement Learning through immersive, session-based modules.

---

## 🚀 The Curriculum

Navigate through three specialized training modules, each demonstrating a fundamental RL concept:

### 🎮 Module 01: The Greedy Bandit
*   **Concept**: Exploration vs. Exploitation
*   **The Challenge**: Identify which energy core has the highest hidden reward distribution.
*   **Interactive Feature**: Use the **Hyperparameter Console** to adjust the *Epsilon-Greedy* rate and watch the AI agent learn in real-time.

### ⚡ Module 02: The Glitch Runner
*   **Concept**: Stochastic MDPs (Uncertainty)
*   **The Challenge**: Reach the goal while navigating a "glitchy" signal where movements have a 25% chance of redirection.
*   **The Lesson**: Learn to develop safe policies that succeed even in unpredictable environments.

### 🐍 Module 03: Neon Serpent
*   **Concept**: Deep Q-Learning (DQN)
*   **The Challenge**: Survive and grow in a dynamic grid.
*   **The Innovation**: Watch the **Neural Nexus**—a live visualization of the agent's Neural Network—as it calculates Q-Values for every possible move.

---

## ✨ Premium Features

*   **🏆 Hall of Fame**: A live global graduation dashboard using JSONBin.io to immortalize the most recent seminar graduates.
*   **🧠 Neural Nexus**: Real-time SVG visualization of deep neural network activity.
*   **🧪 Strategy Console**: Live hyperparameter tweaking (Epsilon, Auto-Pilot) for hands-on learning.
*   **🌊 Liquid Transitions**: Premium screen transitions and sci-fi aesthetics tailored for high-end presentations.
*   **🔐 Session-Only Persistence**: Designed for public seminar use—every refresh starts a clean, new training session.

*   **Persistence**: JSONBin.io (Remote Hall of Fame API)

